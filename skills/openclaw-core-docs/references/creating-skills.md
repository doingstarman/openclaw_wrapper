# OpenClaw Official: Creating Skills (Summary)

Source: https://raw.githubusercontent.com/openclaw/openclaw/main/docs/tools/creating-skills.md

## Key Points

- A skill is a directory containing `SKILL.md` with YAML frontmatter.
- Minimal frontmatter: `name`, `description`.
- Typical local path: `~/.openclaw/workspace/skills/<skill-name>/SKILL.md`.
- Reload skill catalog by opening a new session or restarting gateway.
- Validate load with `openclaw skills list`.
- Keep instructions concise and security-focused (especially for shell-exec behavior).
